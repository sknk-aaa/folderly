# Folderly

Windows フォルダのアイコンをカバー画像とカラータグでカスタマイズするデスクトップアプリ。
C#/.NET 8 WPF + WebView2 + ImageSharp + SQLite + MSIX。
Microsoft Store: [KanekoApps.Folderly](https://apps.microsoft.com/detail/9N99JH5H91H8)
